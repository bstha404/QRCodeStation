# Design system — QR Code Station

Design reference for [qrcodestation.com](https://qrcodestation.com): a free, private QR code generator with light and dark themes, 12 languages (including right-to-left Arabic) and no sign-up.

Source of truth: `src/styles/global.css` and `data-theme` on `<html>`. The site is a static Astro build with plain CSS (no Tailwind, no React). Interactivity is small inline scripts in the components.

## Theme model

Themes are applied with `data-theme="light"` or `data-theme="dark"` on `<html>`.

| Behavior | Detail |
|----------|--------|
| Default | Light (the `<html>` tag ships with `data-theme="light"`; a visitor’s saved choice in `localStorage.theme` overrides it) |
| Persistence | `localStorage.theme` = `"light"` \| `"dark"` |
| Toggle | Header switch with a sun and a moon side by side and a green knob (`.theme-toggle`) |
| FOUC guard | Inline script in `Base.astro` reads `localStorage.theme` before paint |
| Browser chrome | `theme-color` meta: `#F2F5F2` (the light page background) |
| Color scheme | `color-scheme: dark` / `light` so native controls match |
| Transition | Body background and text color ease over `0.2s` |

All colors are CSS custom properties on `:root` / `[data-theme]`. Components only use the tokens below.

### Usage rules

- **Background stack:** `ink` (page) → `panel` (surfaces) → `footer` (site footer). Inputs sit on `ink` inside `panel` cards.
- **Text stack:** `paper` (primary) → `muted` (secondary) → `subtle` (meta, hints).
- **Accent:** `charge` for interactive emphasis only; hover goes to `charge-deep`. No second accent color.
- **Borders:** 1px `line`; selected items switch to `charge`.
- **Selected state (pills, tiles, presets, tabs, swatches):** `border-color: charge` + `color-mix(in oklab, charge 12–15%, transparent)` fill + `charge` text.
- **Selection highlight:** `color-mix(in oklab, charge 35%, transparent)`.
- **Warnings:** the only off-palette color is amber (`.warn`, `#d97706` on a 10% amber tint) for contrast and logo-coverage warnings.
- **QR output colors are user data**, not theme tokens. Presets and the color picker never change the site theme.

### Accent gradient (headlines)

Utility: `.grad-text`

```
120deg → grad-start → charge → charge-deep
```

Used sparingly: the bottom hero line (“looks like yours”) and the large error codes (404 / 500).

## Components

### Header

- Left: brand — logo (34px, 30px on phones) + two lines: **QR Code Station** (never wraps) and the translated tagline **Free QR Code Generator** beneath it.
- Middle (desktop): About us · FAQ · Contact us, active page in `--charge`.
- Right: language menu, theme toggle, and on phones (`< 720px`) a **hamburger** button that opens a sheet with the three links (closes on link tap, outside tap, Escape, or resize).
- Sticky, solid background (no `backdrop-filter`).

### Language menu

- `<details class="lang">`: globe icon + native language name (name hidden under `560px`).
- Dropdown list of 12 languages in their own scripts; the current one is `--charge`. Links go to the same page in the other language, or to that language's home when the page has no translation.

### Theme toggle

- Track `70px × 36px` (`62px × 34px` on phones), `border-line`, `bg-panel`.
- Sun and moon icons side by side; green knob (`--charge`) slides under the active one; the active icon uses `--on-charge`.
- RTL mirrors the knob direction.

### Type bar (content types)

- Row of `.pill` buttons: URL, Text, Email, Phone, SMS, WhatsApp, Wi‑Fi, Contact, Location, Event, Crypto, Review, Feedback, App, Coupon, Payment.
- Wraps on desktop; **single scrollable row** on phones with edge-to-edge bleed.

### Option tabs

- Full-width tab bar: 1 Content · 2 Design · 3 Logo · 4 Colors · 5 Encoding.
- Step number in a mono circle, tab name, and (wide screens) a short summary of the current setting.
- Selected tab: `--charge` text + 2px `--charge` underline. Scrolls sideways on narrow screens.
- **Swipe** on the settings panel: left→right = previous, right→left = next (inverted in RTL). Swipes that start on sliders or text fields are ignored. Arrow keys also switch tabs.

### Cards, panels and help boxes

- `.card` surface: `--panel`, 1px `--line`, 16px radius, content padding `20px`.
- Mobile only: a small “SETTINGS” bar with a round **−/+** button collapses the settings card so the QR stays in view.
- “What each … does” help boxes are separate `.explain` cards: always open on desktop, **collapsed dropdowns on mobile**. Content is data-driven from `src/i18n/c/*.js`.

### Inputs, switches and sliders

- Inputs: `--ink` fill, `--line` border, `--charge` border on focus, 12px radius, URL / email / phone fields stay left-to-right in RTL.
- Switch: 42 × 24 pill, knob moves 18px, checked = `--charge` fill.
- Sliders (`.range`): label and value on one line (value in mono, right-aligned), full-width track below, `accent-color: --charge`. Same layout at every screen size.

### Color presets

- Row of 12 round swatches (black, white, gray, red, orange, yellow, green, teal, blue, purple, pink, brown).
- Tapping one opens 10 shades (light → dark) with a hex tooltip on hover; a pill row chooses what to color (code, gradient end, background, eye frame, eye ball, or logo background / stroke).
- Shared component: `ColorPresets.astro`.

### Design presets and shapes

- Preset grid (`.presets`): thumbnails of a real QR with each style; collapsed state shows **exactly two full rows**, then “Show all {n} presets” (77 today).
- Mode pills: **Shapes + colors** / **Shapes only**, plus **⤮ Shuffle**.
- **QR frame** row (26 frames: label, tag, box, bubble, phone, bag, gift, cup …) with an editable text (long text shrinks, then ends with “…”); Frame color, Frame inside and an optional custom text color live in the Colors tab and only appear once a frame is chosen.
- Shape tiles (`.tile`): square, `14px` radius, selected = charge border + 12% fill.

### Logo uploader

- Dashed `.upload` drop target with “or drag and drop”; dragover turns the border solid `--charge` with a tinted fill.
- Uploaded logos are 64px thumbnails with a small round **−** at the top corner; selected thumbnail has a `--charge` border.
- **Sample logos:** a "No logo" button (circle-slash) plus 12 brand icons from Simple Icons as 44px `.sample-logo` buttons (selected = charge border + 12% fill). Tapping the selected one again removes it.
- **Icon shape** pills (Plain · Square · Rounded · Circle · Hexagon) and an optional **Custom icon color** apply to the samples and to search results. Icons are built by `iconLogo()` in `render.js`; their SVG id names the shape so the logo background / stroke follow it.
- **Brand icon search:** a search field over 3,400+ Simple Icons. The list (`/brand-icons.json`, built from `src/pages/brand-icons.json.js`) loads on the first keystroke; up to 30 matches show; the query never leaves the browser.

### Preview card

- `--panel` card, 24px radius, sticky on desktop.
- `.well` holds the live QR; checkerboard background when the code is transparent.
- Margin (the empty border around the code), Rounded corners and Quality sliders sit under the QR.
- Buttons: full-width primary **Download PNG**, a row of SVG / JPG / WebP, then **Copy SVG · Copy image · Print / PDF**.
- Collapsible “QR details & code” dropdown holds the stats grid and the encoded text / SVG source.

### Buttons

| Variant | Style |
|---------|--------|
| Primary | `bg --charge`, `--on-charge` text, 800 weight, hover `--charge-deep` |
| Default | `--panel` fill, `--line` border, `--charge` text, hover border `--charge` |
| Ghost | Same as default with `--muted` text |
| Pills (filters) | Idle: `--line` border, `--panel`, `--muted`. Active: `--charge` border, 15% fill, `--charge` text |
| Disabled | `opacity: .45` |

### FAQ accordion

- `.faq details` cards with a **+ / −** icon on the **right** of the question (− in `--charge` when open). Question text uses the display weight.

### Contact page

- Two `.contact-card`s (Email, WhatsApp), each with the address/number, a short description, a scannable QR code and a full-width centered button; a third card lists what to include in a message.

### Error pages (404 / 500)

- Centered, large gradient error code, short message, two buttons, popular QR types. All languages are in the page and the matching one is shown from the URL prefix.

### Print / PDF sheet

- Built in a hidden iframe and printed: heading, details box, QR, “Scan to …” line and a footer **“Created with QR Code Station (https://qrcodestation.com)”**.
- Always one A4 page (12mm margins); content is scaled down when it is too tall.

## Internationalization

- 12 languages: English (default, no prefix) plus `/es`, `/ja`, `/fr`, `/de`, `/pt`, `/ko`, `/it`, `/id`, `/ru`, `/th`, `/ar`.
- `<html lang dir>` per page; Arabic uses `dir="rtl"` and logical CSS properties (`margin-inline-*`, `inset-inline-*`, `padding-inline-*`).
- `hreflang` alternates (+ `x-default`) in `<head>` and in the sitemap.
- UI strings live in `src/i18n/<code>.js`; long content (help text, pages, FAQ, example values) in `src/i18n/c/<code>.js`. A missing string falls back to English.

## Motion

| Interaction | Spec |
|-------------|------|
| Theme switch | Knob `translate` over `200ms`; body color `200ms` |
| Hover (pills, tiles, presets, buttons) | Border-color transition `.15s` |
| Swatches / shades | Small `scale` on hover and when selected |
| Tabs | Color and underline transition |
| Keep motion purposeful | A few intentional transitions; no decorative animation |

## Iconography

- Inline SVG, no icon font. Sun, moon, globe, hamburger / close are stroke icons (`stroke-width: 2`, round caps).
- Social platform logos in the URL shortcuts come from the `simple-icons` package at build time, drawn in `currentColor` so they follow the theme (LinkedIn uses a plain “in” badge).
- QR shape thumbnails (body, eye frame, eye ball) are generated in `src/lib/render.js`.

## Do / don't

**Do**

- Use the CSS variables (`--ink`, `--panel`, `--paper`, `--charge`, …) so light and dark stay in sync.
- Keep `--charge` green as the only accent; keep the darker light-theme green (`#3D8A20`) for readable contrast.
- Use logical properties and test Arabic (RTL) for any new layout.
- Add every new visible string to `src/i18n/en.js` (and the other language files) instead of hard-coding English.
- Keep generated QR codes on a white or user-chosen background — never theme-tinted.

**Don't**

- Introduce purple / blue / neon gradients or a second accent color.
- Add ads, pop-ups, sign-up walls or tracking scripts — “no sign-up, no ads” is part of the brand.
- Put `backdrop-filter` on ancestors of fixed or absolute overlays (it breaks the mobile menu and dropdowns).
- Use `<details>` or hidden panels for content that must be visible to search engines on first load.
